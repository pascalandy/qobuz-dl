## Scope and exclusions

The report includes statements and branches under `qobuz_dl/`. Coverage.py reported zero explicitly excluded source lines. It excludes the tests, `scripts/`, build checks, install verification, and opt-in live integration work.

The ordinary test suite uses local fakes, mocks, and synthetic media. It needs no Qobuz credentials, subscription, live Qobuz API, live Last.fm page, or media download. On this Linux run, pytest skipped 31 Windows tests and one macOS test from `tests/test_native_platforms.py`.
